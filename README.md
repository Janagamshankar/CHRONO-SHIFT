# CHRONO SHIFT

> **“Bend Time. Defy Fate.”**  
> Sci-Fi 2D Time-Manipulation Action Runner / Precision Platformer  
> Event: RESPAWN — 2D Game Jam, Pravrutti 2.0  
> Team: PixelForge

---

## Technical Stack
- **Game Engine:** Phaser 3 (v3.88.2)
- **Language:** JavaScript (ES Modules)
- **Build Tool:** Vite (v6.2.0)
- **Physics:** Phaser Arcade Physics
- **Resolution:** 1280 × 720 (Aspect-Preserved Responsive Fit)

---

## Getting Started

### Prerequisites
- Node.js (v18+ recommended, verified on v24.12.0)
- npm (v9+ recommended, verified on v11.6.2)

### Installation
```bash
npm install
```

### Development Server
To launch the local development server:
```bash
npm run dev
```
The game will be available at `http://localhost:3000`.

### Production Build
To create an optimized production bundle:
```bash
npm run build
```
The built files will be located in the `dist/` folder.

### Production Preview
To preview the production build locally:
```bash
npm run preview
```
